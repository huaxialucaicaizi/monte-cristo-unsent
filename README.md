# 基督山：未寄出的复仇

副题：一封迟了十四年的信

可玩版（GitHub Pages）：打开本仓库 Pages 根目录即可，五幕 3D 互动小说，完全静态、离线也能用。

## 在线玩

部署后地址：`https://huaxialucaicaizi.github.io/monte-cristo-unsent/`

## 本地打开

双击 `index.html`（file:// 可用），Three.js r160 已放在 `js/three.min.js`，不连外网。  
手机：把整个文件夹传到手机，用浏览器打开；或任意静态服务器。

## 操作

- 电脑：WASD / 方向键走动；点击画面锁定鼠标视角（Esc 解锁），不支持时按住拖拽；靠近发光物按 E 或点击。
- 手机：左下摇杆走动，屏幕其他处拖拽看方向；轻点远处物件会自动走近，近处轻点直接查看。

## 五幕

1. 马赛夜室：点蜡封 3 次拆信 → 对质 / 装作不知 / 交第三人  
2. 伊夫堡牢房：空白日记，三选一痛句 → 共笔越狱 / 裹尸袋  
3. 宝藏室：羊皮地图 → 伯爵 / 唐泰斯 / 双名（可切换读法）  
4. 巴黎书房：号外 → 揭露 / 拆人生 / 和解；和解进删改馆，点掉墙上「恨 报仇 毁掉 血债」  
5. 死信柜室：信首回响痛句 → 寄出 / 锁柜（点蜡封确认）→ 版本目录，可复制  

复仇路线弹窗为墨黑，和解为羊皮暖光。
